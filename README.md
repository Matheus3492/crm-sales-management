# CRM Sales Management

A local-first CRM system designed to manage customers, leads, sales opportunities, activities, proposals and commercial analytics.

## Project Status

🚧 In development

## Objective

Build a secure and scalable CRM system using free and open-source technologies.

## Planned Features

- User management
- Authentication and authorization
- Customer management
- Lead management
- Sales pipeline
- Kanban board
- Follow-ups
- Meetings
- Proposals
- File attachments
- Sales dashboard
- KPIs
- Sales forecast
- Loss analysis
- Customer lifecycle
- Audit logs

## Technologies

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- HTML/CSS/JavaScript
- Git
- GitHub

## Security

Security will be considered from the beginning of the project, including authentication, authorization, password hashing, input validation, audit logs and protection of sensitive configuration.
